# TTC Material Hub

TTC Material Hub - Project Material & Inventory Management

## Demo Mode
App mặc định chạy Demo nếu không đặt `VITE_APP_MODE=production`.
Demo dùng local browser storage theo cấu hình (sessionStorage hoặc localStorage).
Demo không gọi Firebase.
Demo không gọi Gemini.
Firestore rules đang deny-all.
Data access qua DataProvider.
Demo Reset hoạt động.

Module Project và Monitoring hiện tại chỉ là placeholder.
Module tiếp theo sau baseline là MODULE 1.
